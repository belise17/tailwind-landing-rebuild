# Landing Page Rebuild: Plain CSS vs Tailwind CSS

## Project Overview
This project demonstrates how I rebuilt a landing page originally styled with plain CSS using Tailwind CSS utility classes.

## What Changed in My Workflow?

**Plain CSS:**
- I wrote custom CSS rules for styling.
- I managed styles using separate CSS selectors.
- I manually wrote media queries for responsive layouts.
- I had to manage class names and CSS properties separately.

**Tailwind CSS:**
- I used utility classes directly in HTML.
- I styled elements without writing separate custom CSS rules.
- I used responsive prefixes such as `sm:`, `md:`, and `lg:`.
- I could adjust spacing, colors, typography, and layouts directly in the HTML.

## Conclusion
Rebuilding the landing page with Tailwind CSS made my styling workflow faster and more organized. It also helped me understand utility-first CSS and responsive design.
